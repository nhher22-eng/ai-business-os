# DEC-096 공통 내비게이션·대화형 Agent 업무 진입

- 상태: 확정
- 확정일: 2026-08-27
- 구현 범위: 배포 전 코드·테스트 완료, 운영 배포는 별도 승인

## 결정

1. PC와 모바일은 하나의 공통 메뉴 데이터를 사용한다.
2. PC는 고정 왼쪽 메뉴, 모바일은 로고·`AI Business OS` 상단 바, 전체 메뉴 드로어와 `홈·상품관리·신규등록·전체메뉴` 하단 메뉴를 사용한다.
3. 아직 구현되지 않은 업무는 이동하지 않는 `준비 중` 항목으로 표시한다.
4. 업무 홈의 `신상품 출시·기존 상품 수정·판매채널·콘텐츠 제작`은 모바일에서 2열로 표시한다.
5. 각 업무는 `직접 입력하기`와 `Agent에게 맡기기`를 제공하며 둘은 기존 공통 기능을 사용한다.
6. Agent 흐름은 `요청 → 추가 확인 → 실행계획 → 최종 승인 → 결과 확인`의 5단계다.
7. 요청과 추가 확인은 음성 또는 텍스트로 가능하며 사진·문서를 첨부할 수 있다. 음성 미지원 브라우저에서는 텍스트 입력으로 안전하게 대체한다.
8. 음성으로 승인 의사를 말할 수 있지만 실제 실행은 승인 범위 확인과 `Agent 실행 승인` 버튼으로만 확정한다.
9. 외부 게시·가격 변경·판매 시작은 이번 승인 범위에 포함하지 않으며 별도 승인을 유지한다.
10. 첫 업무 홈 진입 시 `Welcome to AI Business OS` 인트로를 4초간 표시하고 `시작하기`로 건너뛸 수 있다.

## 보존 조건

- 사용자 직접 실행·설정 기반 자동화·Agent 판단 실행은 같은 공통 기능을 사용한다.
- `Agent 실행 허용` 통제를 유지한다.
- 기존 인증, Queue, Worker, Gate, 감사 및 외부 승인 경계를 변경하지 않는다.
- 운영 서버 배포와 GitHub 반영은 새 채팅에서 사용자와 함께 수행한다.
