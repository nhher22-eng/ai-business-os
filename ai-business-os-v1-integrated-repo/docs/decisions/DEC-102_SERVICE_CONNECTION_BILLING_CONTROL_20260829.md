# DEC-102 · 서비스·연결·요금 통합 관리

- 결정일: 2026-08-29
- 상태: 승인

## 결정

AI Business OS 운영 메뉴에 `서비스·연결·요금 관리` 화면을 둔다. 서비스별 연결·인증 상태, 요금제, 결제 확인 상태, 사용량 메모, 당월 비용, 월 예산, 갱신일과 영향을 받는 OS 기능을 한 화면에서 관리한다.

자동 확인이 가능한 상태와 사람이 입력한 결제·사용량 정보는 구분한다. 결제 API가 없거나 연결하지 않은 서비스는 `수동 확인 필요`로 표시하며 정상으로 추정하지 않는다.

## 안전 경계

- 비밀번호, 카드번호, API 키와 토큰 원문을 저장하거나 API·화면에 반환하지 않는다.
- Agent는 외부 결제, 요금제 변경, 카드 등록 또는 중요 권한 승인을 실행할 수 없다.
- 결제·사용량·인증 관리는 등록된 공식 서비스 주소로만 연결한다.
- 외부 공식 화면에서 로그인과 최종 결제·요금제 변경은 사용자가 직접 수행한다.
- Google Drive 재인증은 기존 OS OAuth 흐름으로 연결한다.
- 관리정보 변경 API와 화면은 기존 Dashboard 인증을 요구한다.

## 1차 관리 대상

- OpenAI API
- AWS
- Google Drive
- GitHub
- 네이버 Commerce API
- 운영 알림(SNS·이메일)
- 도메인·SSL
- 향후 외부 시장조사 서비스

## 구현 범위

- 서비스 연결·인증 자동 진단과 진단 방식 표시
- 결제 상태, 요금제, 비용, 예산, 갱신일과 비밀정보가 아닌 운영 메모 저장
- 공식 서비스 관리·결제·사용량 페이지 바로가기
- 서비스 중단 시 영향을 받는 OS 기능 표시
- 전체 비용·예산과 주의 항목 요약
- 비밀정보로 보이는 입력의 저장 차단

실제 공급자 청구 API 연결, 자동 청구서 수집, 예산 초과 시 Agent 실행 차단은 후속 단계로 둔다.
