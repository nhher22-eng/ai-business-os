# DEC-100 범용 Agent 요청창 분리

- 상태: 구현 완료, 배포 전
- 결정일: 2026-08-29
- 관련 결정: DEC-097, DEC-098, DEC-099

## 배경

DEC-099의 전역 `Agent에게 요청` 버튼을 네 가지 대표 업무 화면에 연결하면 기존 `Agent에게 맡기기`와 역할이 중복된다. 전역 호출의 목적은 사용자가 업무 유형을 먼저 선택하지 않고 필요한 업무를 자연어로 요청하는 것이다.

## 결정

1. `/agent-workspace`는 신상품 출시·기존 상품 수정·판매채널·콘텐츠 제작의 네 가지 대표 업무 화면으로 유지한다.
2. `/agent-request`를 별도의 범용 Agent 요청창으로 제공한다.
3. 범용 요청창은 네 가지 업무 선택 카드를 표시하지 않고 `무엇을 도와드릴까요?`로 시작한다.
4. 전역 `Agent에게 요청`과 상품별 `이 상품을 Agent에게 요청`은 `/agent-request`로 연결한다.
5. 상품 화면에서 호출하면 현재 상품 ID와 호출 화면을 자동 연결한다.
6. 자유 요청은 공통 도구 레지스트리로 해석하고 기존 확인·계획·승인·결과 흐름을 재사용한다.
7. 조회는 실행 확인, 내부 변경은 최종 승인, 미지원 요청은 실행 중단 원칙을 유지한다.

DEC-099의 전역 호출 목적은 이 결정으로 구체화하며, 네 가지 대표 업무 화면과 범용 요청창을 명확히 분리한다.
