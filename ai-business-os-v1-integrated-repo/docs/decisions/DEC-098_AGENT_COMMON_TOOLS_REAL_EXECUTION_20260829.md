# DEC-098 Agent 공통 도구와 실제 실행 검증

- 상태: 구현 완료, 배포 전
- 결정일: 2026-08-29
- 관련 결정: DEC-097

## 배경

Agent 화면의 대화·계획·승인 UI는 있었지만, 승인 뒤 실제 상품 데이터가 변경되지 않아도 완료처럼 보일 수 있었다. 또한 사용자가 정확한 상품명을 기억하지 못하는 경우와 새 명령을 추가하는 방법을 공통 구조로 정리할 필요가 있었다.

## 결정

1. Agent 실행은 `agent-tool-v1` 공통 프로토콜과 도구 레지스트리로 관리한다.
2. 조회 도구는 판매가, 배송비, SKU 구성, 대표이미지, 등록 이미지, 상세페이지, 카테고리 상품, 네이버 내부 연결 상태를 지원한다.
3. 변경 도구는 우선 상품 이미지 추가와 SKU 추가만 실제 실행한다.
4. 상품명은 공백 제거·부분 일치·유사도 점수로 후보를 제시한다. 변경 작업은 후보가 하나여도 사용자가 대상 상품을 확인한 뒤 실행한다.
5. 내부 변경 도구는 계획 확인과 명시적 최종 승인이 필요하다.
6. 변경 완료는 데이터베이스 저장 후 재조회 검증이 성공한 경우에만 표시한다.
7. 등록되지 않은 요청은 `요청 기록 완료 · 실제 상품 변경 없음`으로 표시하며 완료로 오인시키지 않는다.
8. 네이버 상태 조회는 현재 내부 연결 기록만 확인한다. 실제 네이버 전시 상태는 향후 채널 API 연결 뒤 별도 검증한다.

## 지원 명령 예시

- 블루베리 비료 상품 판매가 알려줘
- 블루베리 비료 배송비 알려줘
- 블루베리 비료 SKU 구성 알려줘
- 블루베리 비료 대표이미지 보여줘
- 블루베리 비료 등록이미지 모두 보여줘
- 블루베리 비료 상세페이지 보여줘
- 블루베리 비료 상품에 사진 추가해줘
- 블루베리 비료 상품에 5kg 입제 지퍼백 SKU를 추가하고 판매가는 25,000원으로 해줘
- 방충망 카테고리에 등록된 모든 상품 보여줘
- 블루베리 비료가 네이버에 등록되어 있는지 확인해줘

## 범위 밖

- 네이버 등 외부 판매채널에 상품을 실제 등록·수정·판매 시작하는 기능
- 모든 자유형 명령을 자동 실행하는 범용 업무 실행기
- 관리자 화면에서 도구를 직접 추가하는 설정 UI

도구 설정 UI와 외부 채널 실시간 검증은 공통 실행 구조가 운영에서 안정화된 뒤 별도 결정으로 구현한다.
