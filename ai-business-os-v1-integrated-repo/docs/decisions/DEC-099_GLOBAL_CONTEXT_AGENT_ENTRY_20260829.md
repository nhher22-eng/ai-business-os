# DEC-099 전역·현재 상품 기반 Agent 호출

- 상태: 구현 완료, 배포 전
- 결정일: 2026-08-29
- 관련 결정: DEC-097, DEC-098

## 결정

1. 네 가지 대표 Agent 업무 메뉴는 유지한다.
2. 모든 업무 화면에 `Agent에게 요청` 전역 호출 버튼을 제공한다.
3. 상품 상세 화면에는 `이 상품을 Agent에게 요청` 버튼을 제공한다.
4. 상품 화면에서 호출하면 현재 상품 ID와 호출 화면을 Agent 작업공간에 자동 연결한다.
5. 호출 위치가 달라도 기존 공통 도구와 `요청 → 확인 → 계획 → 실행 확인/최종 승인 → 결과` 흐름을 재사용한다.
6. 조회 도구는 실행 확인, 내부 변경 도구는 명시적 최종 승인을 계속 요구한다.
7. 등록되지 않은 일반 요청은 승인 없이 임의 실행하지 않고 지원 범위를 안내한다.

## 1차 구현 범위

- 데스크톱과 모바일의 전역 Agent 호출
- 현재 화면에 따른 대표 업무 유형 자동 선택
- 상품 상세 화면의 현재 상품 자동 연결
- 연결 상품을 계획 단계의 우선 후보로 지정

업무별 빠른 실행 버튼은 실제 사용 빈도를 확인한 뒤 공통 도구 레지스트리를 재사용해 추가한다.
