# DEC-101 · Agent 상품 통합정보 조회 범위

- 결정일: 2026-08-29
- 상태: 승인

## 결정

일반 Agent 요청 창은 상품별 통합관리의 일곱 영역을 공통 조회 계층으로 읽는다.

1. 상품정보
2. 상품설명
3. 옵션·SKU
4. 가격·재고·배송
5. 등록자료
6. 판매콘텐츠
7. 판매채널

사용자는 상품 전체 정보 또는 특정 영역을 자연어로 요청할 수 있다. 조회 결과는 저장된 내부 데이터만 사용하며, 값이 없으면 `미등록`으로 표시한다.

## 경계

- 이 조회는 데이터 변경을 일으키지 않으며 승인이 필요 없다.
- 기존 내부 쓰기 도구의 승인 단계는 유지한다.
- 판매채널 정보는 내부 연결 기록이다. 외부 마켓의 실시간 전시·판매 상태로 단정하지 않고 별도 API 검증이 필요함을 표시한다.
- AI 제안과 미확정 값으로 누락된 상품 FACT를 만들어내지 않는다.

## 검증 기준

- 상품설명, 특징, 사용방법 등의 영역별 요청이 지원된다.
- 전체 정보 요청은 일곱 영역을 모두 반환한다.
- SKU, 등록자료, 이미지, 상세페이지, 승인 문안, 판매채널 기록이 해당 영역에 포함된다.
- 누락 값은 화면에서 `미등록`으로 표시된다.
