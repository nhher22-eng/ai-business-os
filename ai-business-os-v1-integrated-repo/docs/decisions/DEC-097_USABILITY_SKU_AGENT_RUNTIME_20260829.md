# DEC-097 상품 자료·SKU·Agent 실행 개선

- 확정일: 2026-08-29
- 적용 범위: PC·모바일 공통
- 외부 판매채널 실행: 제외, 별도 승인 유지

## 결정

1. 신규 상품 등록의 이미지·문서 선택은 한 번에 한 장 또는 여러 장을 허용한다.
   이후 한 장 또는 여러 장을 다시 선택해도 기존 선택을 덮어쓰지 않고 누적한다.
   파일명·용량·개별 삭제를 제공하고 동일 파일의 중복 추가를 막는다.
2. 상품별 통합관리의 등록 자료에도 `이미지 추가`를 제공한다. 대표·우측 45도·정면의
   `교체`는 지정 슬롯만 바꾸며 원본 추가와 구분한다.
3. 새 SKU는 연결 이력이 없을 때 삭제할 수 있다. 연결 이력이 있으면 삭제하지 않고
   비활성화한다. 비활성 SKU는 가격·재고·배송 및 판매채널 기본 화면과 활성 SKU 개수에서
   제외한다. 재활성화 시 저장된 내부 가격·재고 값은 보존한다.
4. Agent에게 맡기기의 모든 단계에서 중복된 `직접 입력하기` 버튼을 제거한다.
   텍스트 입력란은 항상 표시하고 음성 입력은 같은 입력란에 누적한다.
5. 계획 단계에는 텍스트 수정 요청란, 말하기, 계획 수정 요청, 계속 버튼을 제공한다.
6. 요청 없이 확인·계획·승인·결과 단계로 이동할 수 없게 한다. 승인 시 실제 Run API를
   호출하고 Agent Control의 ON·PAUSE·OFF 경계를 적용하며 실행 상태와 결과를 조회한다.
7. Agent Control은 공통 8시간 로그인 세션을 인정한다. 별도 Bearer Token은 비상·관리용
   대체 인증으로 유지한다.

## 안전 경계

- Agent 실행 승인은 내부 Run 실행만 허용한다.
- 외부 게시, 판매 시작, 외부 가격·재고 변경은 이번 범위에서 실행하지 않는다.
- 첨부 원본은 덮어쓰지 않는다.
- 판매채널 연결 이력이 있는 SKU는 물리 삭제하지 않는다.

## 검증 기준

- 파일 선택을 여러 번 반복해도 누적되고 중복은 한 번만 표시된다.
- SKU 비활성화 후 가격·재고·배송 및 판매채널에 나타나지 않는다.
- 삭제 가능한 SKU는 재조회 후 사라지고 연결 이력이 있으면 409로 보호된다.
- Agent 단계는 순서대로만 진행되며 승인 전 Run이 생성되지 않는다.
- PAUSE/OFF 상태에서는 Run 생성이 409로 차단된다.
- 공통 로그인 세션으로 Agent Control 상태 조회가 가능하다.
