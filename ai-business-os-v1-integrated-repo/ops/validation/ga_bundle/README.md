# AI Business OS v1.0 GA Release Bundle

이 번들은 RC5 → GA 전환을 위한 최종 출하 구조의 초도본이다.

## 포함 범위
- HP-05 GA Evidence Finalizer
- Release manifest / checksum
- Helm / Kustomize / Docker Compose 배포 골격
- 운영 Runbook
- Backup / Restore / Incident / Rollback 절차
- Security checklist
- Monitoring baseline
- CI release gate
- GA sign-off checklist

## 중요
현재 번들은 실제 운영 인프라에 연결되기 전 단계의 배포 가능 구조다.
실제 GA 승인은 HP-02~HP-04의 live evidence와 운영 인프라 검증이 결합된 후 확정해야 한다.
